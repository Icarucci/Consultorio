## CONSULTORIO

Repositorio de Proyecto para la materia Programacion I, Programacion Orientada a Objetos.
_Proyecto de consultorio multidisiplinario con un menu de visualizacion en Java Option Pane_

## Estructura de paquetes

- utils: Clases utilitarias para el manejo de metodos estaticos
            Arreglos: ingreso de elementos, ordenacion y busqueda
            IO: manejo de input/output con validacion de datos
            
- objetos: Clases para instanciar objetos 

- view: Clases para el manejo de la visualizacion de los menus

- Controller: maneja la logica mas compleja de la app.

Se intenta realizar una separacion MVC - 
Donde el modelo gestiona los atributos y los metodos basicos de los objetos
La vista se encarga de el ingreso de los inputs y del muestreo de datos.
Los controladores manejan la logica mas compleja e instancian los objetos necesarios.
